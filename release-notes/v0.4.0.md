# Reverse Bin Detector v0.4.0

Ships with reverse-bin v0.4.0; was 0.1.22.

- `detectorschema` dropped; output unchanged.
- Health: default `/`, status may be `2xx`.
- Unknown `REVERSE_BIN_*` keys fail. `LISTEN` removed.
- Python kind removed: executable `main.py` needs `REVERSE_BIN_COMMAND`.
- Sandbox escape fixed: app env ran code unsandboxed (`PATH` chose `landrun`; `LD_PRELOAD`). glibc-distrusted variables refused.
- `SOCKET_PATH`: directory created, stale socket removed.
- `sh` is PID 1: apps get SIGTERM.
- landrun v0.2.0, strict mode.
- Apps bind only their port, plus `REVERSE_BIN_BIND_TCP` (`0`: ephemeral).
- Linux 7.1+: unix connects only in app dir and resolver's.
- `--as-app` plans in-process.
