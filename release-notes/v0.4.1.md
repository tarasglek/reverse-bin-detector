# Reverse Bin Detector v0.4.1

Ships with reverse-bin v0.4.0.

- Every app may bind ports the kernel picks (`bind` to port 0), socket apps too. Dev servers and test runners with a second, ephemeral port need no `REVERSE_BIN_BIND_TCP` now.
- `REVERSE_BIN_BIND_TCP` is for fixed extra ports only; `0` there is accepted and changes nothing.
- Choosing a fixed port still needs the key. Landlock never governed `listen()` without `bind()`, which always got a kernel-picked port.
