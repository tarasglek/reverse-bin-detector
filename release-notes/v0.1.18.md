# Reverse Bin Detector v0.1.18

## Highlights

- Sandboxed apps can resolve DNS on hosts where `/etc/resolv.conf` is a symlink out of `/etc`, such as systemd-resolved's `../run/systemd/resolve/stub-resolv.conf`.

## Breaking changes

None.

## Full list of changes

- The detection Landlock policy and the runtime landrun policy now come from one `Policy` type in `internal/sandbox`; `wrapRuntimeSandbox` only renders it.
- When `/etc/resolv.conf` is a symlink, its target's parent directory is granted read-only, so resolver rewrites that replace the file stay readable. Parents already granted, broad directories (`/`, `/run`, `/var`, `/tmp`, `/home`, `/root`) and ancestors of the app directory are never granted; static apps get no such grant.
- landrun flags are emitted one path per flag, with `--env` after the filesystem and network flags. The set of grants is otherwise unchanged.
