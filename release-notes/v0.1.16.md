# Reverse Bin Detector v0.1.16

## Highlights

- New `--public-url=https://app.example.com` flag injects `REVERSE_BIN_PUBLIC_URL` and `REVERSE_BIN_PUBLIC_HOST` into the app environment, so apps no longer hard-code their own domain for CSRF origins, allowed hosts, OAuth redirects, or absolute links.

## Breaking changes

None. Without `--public-url` the app environment is unchanged.

## Full list of changes

- Add `--public-url`; it must be an origin (scheme, host, optional port) and is validated, with a trailing `/` stripped.
- Inject `REVERSE_BIN_PUBLIC_URL` (origin) and `REVERSE_BIN_PUBLIC_HOST` (hostname, no port); values set in the app `.env` or `secrets.enc.json` take precedence, and an app-set URL also drives the derived host.
- Forward `--public-url` through `--as-app` so sandboxed shells see the same environment as the served app.
