# Reverse Bin Detector v0.1.14

## Highlights

- Add `rb-ssh`: invoked through an `rb-ssh` symlink, the detector maps a per-app SSH key to an interactive shell or one-off command inside that app's runtime sandbox.
- `--as-app` now execs the sandbox, so hangups and signals can no longer orphan sandboxed processes.

## Breaking changes

None.

## Full list of changes

- `rb-ssh` accepts only `rb-ssh APP` or `rb-ssh -c "<dir>/rb-ssh APP"`, so it is safe as the service user's login shell; it refuses sftp and scp and uses compiled-in `PATH`, apps root, and age key paths.
- `rb-ssh` sessions die with their sshd session process, including sessions without a PTY.
- `--as-app` replaces the detector process with the sandbox launcher instead of supervising it.
- Explain how to create a missing app `data/` directory.
- Use a shell builtin in the fake SOPS test helper.
