# Reverse Bin Detector v0.1.13

## Highlights

- New `--sandbox-exec APP_DIR -- COMMAND [ARGS...]` mode runs one-off commands with the exact environment, working directory, runtime sandbox, and namespace policy of a detected app.
- Useful for unit tests, migrations, maintenance tasks, cron jobs, REPLs, and interactive shells inside the app runtime.

## Breaking changes

None.

## Full list of changes

- Add `--sandbox-exec` to execute an arbitrary command in the detector-generated app environment.
- Generate the launch plan in a restricted detector child and validate it through the shared schema before execution.
- Preserve the app-kind filesystem and network policy, PID/IPC/UTS namespaces, working directory, and generated environment variables exactly.
- Propagate the executed command's exit status and support noninteractive stdio for cron and tooling use.
- Add `--sandbox-exec-plan` as the private child mode used by the parent process.
