# Reverse Bin Detector v0.1.13

## Highlights

- Add `--as-app` for running one-off commands with an app's detected environment, working directory, and runtime sandbox.
- Run the real Landlock and namespace sandbox in CI instead of reducing test coverage on hosted runners.

## Breaking changes

None.

## Full list of changes

- Generate the `--as-app` launch plan in a restricted child process and execute it in the parent with inherited standard streams and command exit status.
- Normalize relative app paths and default `HOME` to the app's `data/` directory when unset.
- Require structured, version-matched release notes before publishing a release.
- Pin CI vulnerability scanning to a Go 1.25-compatible `govulncheck` release.
