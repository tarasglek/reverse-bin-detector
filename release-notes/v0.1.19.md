# Reverse Bin Detector v0.1.19

## Highlights

- `--as-app-dev APP_DIR -- COMMAND` runs a command in the app's sandbox with the app source writable, for editing and `git push` deploys.
- `rb-ssh` sessions run as `--as-app-dev`, so a per-app SSH key can edit that app's source. With `receive.denyCurrentBranch=updateInstead`, `git push reverse-bin@host:. main` updates the checkout in place.

## Breaking changes

- `rb-ssh` sessions can now modify app source; before, only `data/` was writable. Treat every per-app SSH key as a development credential for that app.

## Full list of changes

- Add `--as-app-dev`: the `--as-app` sandbox with the app directory granted `--rwx` instead of `--rox`. Caddy-launched apps and `--as-app` keep read-only source, so a running app cannot modify its own code.
- The writable grant is one layered setting on the shared runtime policy (`Policy.WithWritable`); the policy is built in one place.
- `rb-ssh` uses the `--as-app-dev` path. sftp and scp are still refused.
