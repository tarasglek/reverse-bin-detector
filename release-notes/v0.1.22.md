# Reverse Bin Detector v0.1.22

- Sandbox: app `data/` granted `--rwx` instead of `--rw`. No effective permission change: `--rox <app-dir>` already allowed exec beneath `data/`. Now explicit, so apps running tools installed in `data/` (uv Python, npm addons, browsers) survive a narrower app-dir grant.
- Built with Go 1.27.4; actionlint v1.84.1.

Breaking: none.
