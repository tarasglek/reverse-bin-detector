# Reverse Bin Detector v0.1.21

- Security: app `data` symlink no longer grants write to another app's dir. `.env`, `secrets.enc.json`, entry points read via `os.Root`; symlinks out of app fail.
- Security: env values no longer in landrun argv (world-readable `/proc/*/cmdline`); passed by name.
- Security: `SOCKET_PATH` must stay inside app; Caddy deleted sockets via `..`.
- Sandbox: landrun only. Detection self-sandbox and go-landlock removed. sops runs under landrun, ciphertext on stdin, no network. Unpins landrun (v0.1.17 scopes abstract sockets, signals). Refuses below Landlock ABI 6.

Breaking: `--allow-unsafe-no-landlock` removed; use `--no-runtime-sandbox` (tests only).
