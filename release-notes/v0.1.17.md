# Reverse Bin Detector v0.1.17

## Highlights

- Apps get one public-address variable, `REVERSE_BIN_PUBLIC_HOST`, and are always served as `https://$REVERSE_BIN_PUBLIC_HOST`.

## Breaking changes

- `--public-url` is replaced by `--public-host=host[:port]`, and `REVERSE_BIN_PUBLIC_URL` is no longer injected. Callers passing `--public-url` (reverse-bin-hosting v0.0.10 Caddyfiles) must switch to `--public-host` with a bare host.

## Full list of changes

- Replace `--public-url` with `--public-host`, validated as `host[:port]` and lowercased.
- `REVERSE_BIN_PUBLIC_HOST` keeps any port, so local HTTPS runs such as `app.localhost:9443` produce correct origins; v0.1.16 stripped it.
- An app-set `REVERSE_BIN_PUBLIC_HOST` still wins and is validated.
- `--as-app` forwards `--public-host`.
