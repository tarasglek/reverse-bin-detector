# Reverse Bin Detector v0.1.15

## Highlights

- Apps without a `data/` directory run read-only again instead of being refused at plan time.

## Breaking changes

None.

## Full list of changes

- Drop the plan-time `data/` check added in v0.1.14. The runtime sandbox grants write access to `<app>/data` only when it is a directory, so apps without one run read-only; apps that need to write fail at runtime with an error naming the `data/` path.
