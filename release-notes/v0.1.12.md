# Reverse Bin Detector v0.1.12

## Highlights

- Static applications now use isolated, reverse-bin-managed Unix sockets instead of TCP listeners.
- Executable applications use one consistent networking policy and can read sysfs when sandboxed.

## Breaking changes

Static applications no longer accept `SOCKET_PATH`, `REVERSE_BIN_PORT`, `REVERSE_BIN_HOST`, or `LISTEN` overrides. Their transport is managed automatically.

## Full list of changes

- Serve static applications through deterministic sockets under `/run/reverse-bin/static-apps`, granting write access only to the managed socket directory.
- Give command, Deno, and Python applications unrestricted networking rather than mixing unrestricted access with port-specific bind grants.
- Mount `/sys` read-only for executable applications so runtimes can inspect system information without gaining write access to sysfs.
