# Reverse Bin Detector v0.2.0

For reverse-bin v0.4.0; ship together. App configuration unchanged.

- One package; `detectorschema` dropped. Output fields unchanged.
- Health: default `/` (was the Caddyfile's); `REVERSE_BIN_HEALTH_STATUS` accepts `2xx`; method or path alone allowed.
- Unknown `REVERSE_BIN_*` keys fail. `LISTEN` removed.
- `SOCKET_PATH`: directory created; stale socket removed in the launched command.
- Apps now receive SIGTERM. Each app runs in its own PID namespace, and was its PID 1; Linux ignores signals a PID 1 has no handler for, so every stop waited out reverse-bin's 10s grace and ended in SIGKILL. Now `sh` is PID 1 and runs the app as its child: stopping four apps went from 10.1s to 0.06s. `deno serve --watch` ignores SIGTERM itself and still takes the grace.
- `--as-app` plans in-process.
